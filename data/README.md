# Data

## Not included in the repository

| File | Why it is not included |
|---|---|
| `raw/AirlineReviews.csv` | Original dataset (123 MB): over GitHub's 100 MB file limit, and it is third-party content |
| `processed/*.csv` | Intermediate files with the full review text, regenerated by the pipeline |

**Source:** Kaggle "AirlineReviews" dataset, with reviews collected from Skytrax (airlinequality.com).
Download: [128k Airline Reviews on Kaggle](https://www.kaggle.com/datasets/joelljungstrom/128k-airline-reviews) (129,455 reviews)

Download it and save it as `data/raw/AirlineReviews.csv`.

## Included

| File | Contents |
|---|---|
| `dashboard_data.csv` | One row per review: airline, overall score, recommended (yes/no), sentiment. No review text. |
| `results/risultati_temi_sentiment.csv` | Every BERTopic theme per airline, with review count, % negative and keywords |
| `results/temi_principali.csv` | The five themes compared in the thesis (Chapter 5), grouped and labelled by hand from the BERTopic output and used by the dashboard |

For a theme that did not emerge for an airline (check-in for EasyJet), the row is **absent**, not 0%.
